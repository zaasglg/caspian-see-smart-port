# Caspian Smart Port AI — функционал проекта

Ситуационный центр порта **Актау (KZAAU)**: карта, ИИ-назначение причалов, мультимодальная логистика (судно → причал → КТЖ), KPI, алерты и живая погода.

---

## Для кого и режимы доступа

### Гость (без входа)
- Полный просмотр ситуационного центра: обзор, карта, расписание, причалы, алерты.
- Переключатель **AI Optimizing / Manual**.
- Демо-флот из 6 судов (не сохраняется).
- Нельзя добавлять/редактировать суда — на карте и в профиле предлагается регистрация/вход.

### Авторизованный оператор
- Те же экраны, но данные флота — **свои суда из MySQL**.
- Страница **Профиль**: CRUD судов, шаблон флота, очистка, клик по карте для координат.
- В шапке: Профиль, выход, счётчик судов.

## Авторизация и сессии

- **Регистрация** — имя (≥ 2), email, пароль (≥ 6); дубликат email → ошибка 409.
- **Вход** — email + пароль (хеш SHA-256 от `email:password`).
- **Выход** — сброс cookie, редирект на главную.
- **Сессия** — httpOnly cookie `csp_session`, HMAC (`AUTH_SECRET`), 30 дней, `SameSite=lax`.
- При загрузке приложения вызывается `GET /api/auth/me`.
- Пользователи в таблице MySQL `users`.

## Управление флотом

Доступно на `/profile` после входа.

**Типы груза:** Oil · Grain · Container.

**Поля судна:** название, груз, осадка (м), ETA (мин), тоннаж, lat/lon, предпочтительный причал (фильтр по типу груза).

**Действия:**
- добавить судно;
- удалить судно;
- **Шаблон флота** — заменить на демо-набор;
- **Очистить** — удалить весь флот;
- клик по карте — поставить метку и заполнить координаты.

Данные хранятся в MySQL `vessels` (API `/api/vessels`, `DELETE /api/vessels/[id]`).

Выбор судна (карта / таблица / алерт) открывает **drawer**: статус, причал, поезд КТЖ, ожидание, демередж, окно выгрузки.

## Карта (`/map` и профиль)

- Leaflet + react-leaflet, подложка **Carto light** (OSM).
- Центр: паромный терминал порта Актау ≈ `43.6001, 51.2187`.
- Слои: **Причалы / Суда / КТЖ / Маршруты**.
- Маркеры причалов, судов (цвет по грузу), поездов КТЖ, черновая метка при клике.
- Пунктирные линии: судно → причал → поезд при назначении.
- Клик по судну → выбор + drawer.
- Авто-подгонка bounds; на профиле — клик для координат.

## Режимы AI и Manual

Переключатель в шапке на всех порт-страницах.

### AI Optimizing
1. Сортировка судов по ETA (затем по осадке).
2. Выбор причала с минимальным ожиданием среди совместимых (груз + осадка); учёт предпочтительного причала; при равенстве — запас по осадке.
3. Подбор поезда КТЖ с минимальным простоем вагонов относительно готовности причала.

### Manual (Chaos)
1. Порядок судов как есть.
2. Предпочтительный причал, иначе первый совместимый.
3. Первый подходящий поезд; полный штраф ожидания поезда.

### Общие правила
- Совместимость: тот же тип груза и `maxDraft ≥ draft`.
- Статусы: `OPTIMAL` · `WAITING` (> 30 мин) · `STORM_DELAY` · `DRAFT_WARNING` (запас < 0.4 м).
- Длительность выгрузки ≈ 45 мин на 1000 т.
- Нет подходящего причала → ожидание / штормовая задержка (+240 мин к компоненте ожидания).

Логика в `src/lib/logic.ts` (клиентский сценарий, без внешнего ML API).

## Погода и шторм

- Живые данные **Open-Meteo** по координатам порта, обновление ~каждые 5 минут.
- Шторм, если ветер **> 12 м/с** (`STORM_WIND_THRESHOLD`).
- При шторме: глобальная задержка **+180 мин**, статус `STORM_DELAY`, красный баннер, критические алерты.
- При сбое API — запасной mock (5.5 м/с, 22 °C, безопасно).
- В шапке: ветер м/с, температура °C, флаг шторма; часы `Asia/Aqtau`.

Симулятор шторма вручную **не используется** — только реальная (или fallback) погода.

## KPI, экономия, расписание, причалы, алерты

### KPI (обзор)
- Среднее ожидание (мин)
- Вагоно·часы КТЖ
- CO₂ (т)
- Демередж (USD)
- Дельта % относительно противоположного режима (AI ↔ Manual)

### Баннер экономии AI
Сравнение с «хаосом»: демередж $, CO₂ т, ожидание мин, вагоно·ч (+ %).

### Расписание
Таблица: судно, груз, причал, КТЖ, ожидание, статус + Gantt по слотам назначений.

### Причалы
Пять смоделированных причалов **B1–B5** (нефть, зерно, контейнеры, паром/Ro-Ro): % загрузки, назначенное судно / свободен, Gantt.

### Алерты
До 8 штук, сортировка по severity:
- глобальный шторм;
- задержка судна из‑за шторма;
- конфликт осадки;
- долгое ожидание (> 60 мин);
- нет причала;
- простой КТЖ (> 45 мин);
- info при суммарном демередже > $50k.

На карте — боковая панель; на `/alerts` — фильтры (все / critical / warning / info) и переход к судну по клику.

### Экономические константы симуляции
- Демередж: **$8500 / час**
- Холостой расход топлива: **1.8 т / час**
- Фактор CO₂: **3.15**
